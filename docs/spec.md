# 筋トレ自己管理アプリ 仕様書
 
## 概要
 
筋トレを効果的に続けるための自己管理Webアプリ。
実施した種目と使った筋肉を記録し、休ませるべき筋肉と使える筋肉を把握できる。設定した予定に合わせてメールで知らせ、メールから記録フォームへすぐ移動できる。
 
## 技術
 
- Laravel（Livewire スターターキット、認証は Laravel Fortify）
- 詳細は `AGENTS.md` を参照
## ゴール
 
- 自分がした種目などを入力し、使った筋肉と休ませるべき筋肉を把握できる
- 使える筋肉に効果的なトレーニングを提案してもらえる
- 自分が使う筋肉・時間・場所・メニューを設定し、その時間にメールで知らせてもらえる
- メールから筋トレ内容入力フォームへ移動できる
- 休息中の筋肉を使おうとしたときに確認が出て、無理なトレーニングを防げる
- 許可した人と記録や継続日数を見せ合える
## 機能要件
 
優先度：**必須** / 任意（あるとよい）
 
| # | 機能 | 優先度 | 内容 |
|---|---|---|---|
| F1 | 筋トレ記録の入力 | 必須 | 実行日時、メニュー、使用した筋肉、休憩日数を入力して保存する |
| F2 | 休息状況の把握 | 必須 | 記録から、休ませるべき筋肉と使える筋肉を表示する |
| F3 | おすすめ種目の提案 | 必須 | 使える筋肉に効果的な種目を提案する |
| F4 | 休息中の筋肉の確認 | 必須 | 休息中の筋肉を使おうとしたら、保存前に確認を出す |
| F5 | 通知プランの設定 | 必須 | 使う筋肉・時間・場所・メニューを設定する |
| F6 | メール通知 | 必須 | 設定した時間に、設定内容をメールで送る |
| F7 | メールから入力フォームへ移動 | 必須 | メール内のリンクで入力フォームを開く |
| F8 | 記録の閲覧と閲覧許可 | 必須 | 他のユーザーの記録を見られる。許可したユーザーのみ |
| F9 | 継続日数の表示 | 任意 | 継続日数を表示し、他の人のものも見られる |
| F10 | 初心者向けテンプレート | 任意 | 選ぶとフォームに内容が入る |
| F11 | 筋トレの豆知識ブログ | 任意 | ホームページに掲載する |
 
## 各機能の詳細
 
### F1 筋トレ記録の入力
 
- 入力項目：実行日時、メニュー、使用した筋肉、休憩日数
- **メニューのみ自由入力**。それ以外は選択式
- 種目のマスタから選ぶと、メニュー名・使用筋肉・休憩日数が初期値として入る
### F2 休息状況の把握
 
- 「実行日時 + 休憩日数」が現在より後なら、その筋肉は休息中
- 休息中のテーブルは作らず、記録から毎回計算する
- 記録のない筋肉は「使える筋肉」として扱う
### F4 休息中の筋肉の確認
 
- 入力フォームで休息中の筋肉が選ばれていたら、保存前に確認を表示する
- 確認には、休息中の筋肉名と回復予定日時を表示する
- 「続ける」を選ぶと保存され、「戻る」を選ぶと保存されない
- 確認なしでは保存されない（画面側だけでなくサーバー側でも保証する）
### F5 通知プランの設定
 
- ユーザーが次を設定する：**使う筋肉、時間、場所、メニュー**
- 通知のオン・オフを切り替えられる
- 頻度（毎日か曜日指定か）は未決
### F6・F7 メール通知とフォームへの移動
 
- 設定した時間になると、設定内容（時間・場所・メニュー・筋肉）をメールで送る
- メールには入力フォームへのボタン（リンク）がある
- リンクを開くと、プランの内容が入った入力フォームが開く
- ログインしていなければログイン画面を経由し、ログイン後に元のページへ戻る
- 他人のプランのリンクは開けない
- 同じプランに対して二重にメールを送らない
### F8 記録の閲覧と閲覧許可
 
- アカウント名は常に公開
- それ以外（記録など）は、本人と、本人が許可したユーザーのみ閲覧できる
- ユーザーページとマイページは同じ作りにし、本人の場合だけ入力フォームを表示する
## ページ構成
 
| ページ | 内容 | 対応する機能 |
|---|---|---|
| ホームページ | サービス案内（入力なし）。任意でブログを掲載 | F11 |
| ユーザーページ | 他のユーザーの記録・継続日数を見る | F8, F9 |
| マイページ | 自分の記録を見る。入力フォームを表示 | F1, F2, F3, F8 |
| 筋トレ内容入力フォーム | 記録を入力して保存する。休息中の確認もここ | F1, F4, F7, F10 |
| 通知プラン設定（追加） | 筋肉・時間・場所・メニューを設定する | F5, F6 |

## 懸念点
 
- 休息が終わった筋肉の管理（使わなくなったテーブルが増えること）
  → 休息中のテーブルを作らず、記録から計算することで解決する
